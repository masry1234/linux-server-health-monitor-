
# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of ServerPulse.

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |
| Older versions | No |

## Reporting a Vulnerability

If you discover a security vulnerability in ServerPulse, please report it privately.

Do not disclose the vulnerability publicly until it has been reviewed and addressed.

Please include:
- A clear description of the vulnerability.
- Steps to reproduce the issue.
- Potential security impact.
- Relevant logs or proof of concept, if available.

## Response

We will review vulnerability reports and work to validate and address confirmed security issues.

Please do not include passwords, API tokens, or other sensitive credentials in reports.
